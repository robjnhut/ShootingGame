# 🎯 Shooting Game (Tên game của bạn nếu có)

> A 2D/3D Shooting Game built from scratch. This is a self-taught project to improve my programming skills and understand game development mechanics.

## 🎮 Giới thiệu (About the Project)
Đây là một tựa game bắn súng được tôi tự tìm tòi và phát triển. Thông qua dự án này, tôi muốn áp dụng các kiến thức về lập trình hướng đối tượng (OOP), quản lý trạng thái (state management), và xử lý va chạm (collision detection) vào một sản phẩm thực tế.

## ✨ Tính năng nổi bật (Key Features)
* **Player Mechanics:** Di chuyển mượt mà, hệ thống ngắm bắn và các loại vũ khí khác nhau.
* **Enemy AI:** [Mô tả ngắn gọn về kẻ thù, ví dụ: Kẻ địch tự động bám theo người chơi / Các đợt quái vật ngẫu nhiên].
* **Scoring System:** Hệ thống tính điểm và lưu điểm cao (High score).
* **UI/UX:** Màn hình Start, Game Over và Pause menu trực quan.
